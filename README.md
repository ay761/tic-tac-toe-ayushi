# Tic-Tac-Toe (Simple CLI)

This is a small, beginner-style Tic-Tac-Toe game written in Python.

How to run:

1. Open a terminal (PowerShell on Windows).
2. Change directory to this folder:

   cd "C:\Users\Sonali\OneDrive\ドキュメント\ayushi"

3. Run the script:

   python tic_tac_toe.py

The script will ask for two player names and then let players enter moves by typing a number from 1 to 9.

Board positions are numbered like this:

1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9

Enjoy!
